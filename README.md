# Crud

API REST desenvolvida com Java e Spring Boot para gerenciamento de usuários e tarefas, utilizando arquitetura em camadas e persistência em banco PostgreSQL.

---

# Tecnologias utilizadas

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- PostgreSQL
- H2 Database
- Lombok
- Maven
- JUnit / Spring Boot Test
