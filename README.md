# Crud

API REST desenvolvida com Java e Spring Boot para gerenciamento de usuários e tarefas, utilizando arquitetura em camadas e persistência em banco PostgreSQL.

---

# Tecnologias utilizadas

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- PostgreSQL
- H2 Database
- Lombok
- Maven
- JUnit / Spring Boot Test

---

# Estrutura do projeto

```text
src/main/java/joaocarlos/crud

├── controller
├── dto
├── entity
├── repository
├── service
└── CrudApplication.java

---

# Objetivo do projeto

Este projeto tem como objetivo praticar os principais fundamentos de uma API REST com Spring Boot:

criação de endpoints;
uso de DTOs;
persistência com JPA;
conexão com PostgreSQL;
separação entre Controller, Service e Repository;
testes de API.
